# 0.1.0-rc.1

本候选提供单实例Docker/Compose部署：前后端镜像、内部PostgreSQL/Redis、可选监控、显式迁移、首位管理员、停写备份及空目标恢复。版本内容由最终Git提交和发布包SHA-256确定。

包含近期监控合并与功能收敛：标题使用首问摘要/手动改名；退役分支创建、个人模板和搜索CSV，历史会话/引用/收藏保留。中文输入法确认回车不误发送，Markdown引用原文正常排版，来源预览在中等桌面宽度保持侧栏布局。

修复发布审查发现的回收站与事务问题：全局文档回收站排除已删除知识库；批量收藏、取消收藏、分类移动和删库在数据库失败时整批回滚，分类移动只更新相关字段。

升级需要核对048及两份049完整文件名。`049_retire_personal_chat_features.sql`删除个人模板正文和分支请求幂等字段，升级前保留可恢复备份；`049_document_job_traceparent.sql`增加任务父追踪上下文。不要对已有库重放全部迁移。

范围：单后端/worker、本地文件卷为已验收部署路径；MinIO/OCR按启用情况另验收。真实模型验证为6题合成资料和一条流式请求，不能替代业务语料质量验收。目标服务器需自行提供域名、TLS、网络边界、凭据和备份存放策略。
