- 043 建立独立 PDF 文本快照表，避免列表轮询加载全文；快照、片段、Embedding 来源与成功终态原子发布。失败/取消保留上一份已发布内容，版本比较读取快照，不在 HTTP 预览或比较请求中再次运行 OCR。
- 识别进度、剩余无文字页、OCR 页码与未发布结果均有提示。取消后保留的最后一条 `running` 进度，在失败文档响应中归一为 `failed`，界面不会继续显示“正在 OCR”；即时取消响应、只读成员再次读取和真实浏览器复验通过。
- parser/processor/repository/service/retrieval/config 回归覆盖输出上限、命令取消与超时分类、混合页、空白页、失败不发布、重处理保留旧快照、引用来源及配置边界。输出缓冲区禁止通过 `bytes.Buffer.ReadFrom` 绕过限额，对真实子进程输出超限有回归。
