# 前端 UI/UX 优化验收

日期：2026-09-30。承接阶段一方案，用户已确认“可以，先按照这样”，本轮完成阶段二实现及验收收尾。

## 实现结果

| 范围 | 结果 |
| --- | --- |
| 视觉基础与布局 | 沿用 React、自建组件、Lucide 和蓝色明暗主题；背景改为中性灰，成功状态独立用绿色，收紧圆角和间距。完整导航 224px、顶栏 56px；复用 PageHeading，减少列表外层面板。 |
| 首页与知识库 | 压缩首页提问和快捷操作区域，最近动态更靠前；待处理状态加载失败有分区重试。保留列表默认偏好、分类、卡片、筛选和批量操作；窄屏分类可折叠。概览与设置沿用原结构并统一共享样式。 |
| 文档列表与阅读 | 文件名筛选用途明确，列表对齐与状态保留；专用阅读抽屉扩大至 960px，正文随抽屉连续滚动，完成状态更加紧凑。Markdown 提供排版阅读和完整原始文本，TXT/DOCX 保留纯文本；PDF 保留查看器并预留高度。 |
| 搜索 | 明确关键词搜索，结果用分隔线和标题/所属库/摘要形成层级，保留高亮、分页、筛选及导出。 |
| 聊天与来源 | 会话栏 248px，历史筛选用途标清；自动/手动范围在窄屏仍显示。来源在 1600px 以上并排占 400px，较窄视口使用模态抽屉，保留草稿、焦点恢复及引用原文定位。 |
| 局部恢复 | 文档详情、预览、片段各有重试入口；预览和片段重试互不重载，切换文档丢弃旧结果。首页处理中/失败状态分别恢复，不重载动态。 |

未引入新框架、远程字体或详情路由。后端、API、数据库、模型参数、检索/Rerank、上传状态机和权限合同不在本次改动范围。

Markdown 阅读不复用聊天引用解析，原文 `[source: n]` 保持字面值；跳过原始 HTML、保留安全链接并用替代文本展示图片，不自动访问远程图片。

## 验收中修复的问题

1. 原始文本的等宽字号/字体被后续通用预览规则覆盖。提高该变体选择器优先级，浏览器确认使用 14px 等宽字体。
2. 引用片段先于长正文返回时，首次滚动发生过早，迟到正文把已聚焦片段推到视口外。现在等待初始预览完成或失败后定位一次，保留 reduced-motion 和焦点保护。新增延迟预览、预览失败的回归测试；浏览器确认长 Markdown 中目标片段可见且获得焦点。
3. PDF 在解析前后高度变化会影响其下方片段。阅读抽屉内预留 PDF 视口高度，1920×1080 时为 560px，翻页与缩放仍在查看器内部进行。
