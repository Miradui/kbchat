所有阶段均完成后端、前端、受影响回归和规范同步。第 6 项完成后执行全量前后端检查，并在独立 PostgreSQL schema 与 1920×1080 浏览器中验收六项主流程和撤权路径。

## 实现约束

- 保持 `handler → service → repository`、GORM 和现有知识库能力矩阵。收藏和分支仍要求会话属于当前用户，并检查所有依赖知识库；模板和备注仅属于本人。
- 复用现有 Dialog、表单、导入队列、历史定位和消息版本展示；不另建第二套聊天或导入流程。
- 新表/字段使用后续编号迁移，补启动结构检查和真实 PostgreSQL 回归；公开 API 与字段同步 `03/04/09/10` 文档。
- 文档对比使用解析文本，不调用模型生成差异摘要。笔记为收藏回答的个人备注，本轮不增加独立笔记编辑器。
- 表格作为知识资料入库；不执行公式或宏，不增加求和/复杂筛选/跨表统计引擎，不支持旧 `.xls`。XLSX 公式仅使用文件已保存的结果，并明确不重新计算。
- 原有 `.env`、模型和检索默认保持；不做 Rerank/回答质量校准、OCR、URL 入库或任务租约。继续单实例；新功能发布前先完成本地与隔离验证。
- 保留用户已有 `backend/cmd/dbquery/`、`backend/cmd/tmp-explain/`，临时夹具、截图、日志和性能脚本保持在忽略目录。
