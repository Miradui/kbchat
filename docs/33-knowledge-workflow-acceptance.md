# 六项知识工作流验收记录

日期：2026-10-19。范围和实现顺序见 [计划](32-knowledge-workflow-plan.md)。六项已实现，业务 public 与原业务进程没有升级；这份记录区分功能验证与模型质量验证。

## 实现与关键保护

| 功能 | 结果 |
| --- | --- |
| 草稿 | 浏览器按账号/会话/新会话范围保存，切换和刷新恢复，成功回执匹配后清除，失败或状态未知保留。退出清理；50 份/30 天/32000 字符持久化上限。 |
| 指定文档 | 1–20 份、最多 5 库，范围持久化并随分支复制。原库归属变化或文档不可访问时拒绝继续生成；数据库先过滤再 TopN，显式旧版可覆盖库级 current 策略。 |
| 引用版本 | 原文面板按实际发布内容显示新版状态，复用文本对比；携带本回答全部引用的当前有效版本和原问题新建提问，缺失项不造成静默缩小范围。 |
| 在线编辑 | TXT/Markdown 完整原文编辑，最多 1 MiB；新版本沿用上传凭据和事务，重试不重复写入，冲突/失败保留输入。 |
| OCR 校对 | 已发布 OCR 页原图对照，跨页编辑，保存为 PDF 副本+不可变文本基线。事务内锁和指纹防止旧快照覆盖，重处理复用基线；ocr_corrected 随片段、引用、导出传播。 |
| 质量闭环 | 本人自动/多库/指定文档视图，统计和列表同范围鉴权；私人评测保持来源范围并重验实际来源，缺口备注/资料/用例/运行关联可保存，人工解决与重新打开。批量评测避免混选不同范围。 |
