# Perplexity 风格前端与统一导航

日期：2026-10-19。

## 范围与结果

将用户认可的 Perplexity 风格落实到真实 React 前端，保留轻量的 Craft 资料封面。随后按“左边的列切起来十分割裂”的反馈统一各页面左栏，并将前端风格一致性纳入验收。

- 暖白背景、灰绿强调色、墨色主按钮，统一明暗主题、系统字体、圆角、边框与阴影；知识库封面使用低饱和绿、沙、蓝三种色块。
- 新对话使用居中提问区与建议问题；已有对话使用 800px 阅读宽度，输入框位于底部，来源预览保留在右侧。发送按钮保留带可访问名称的圆形箭头。
- 知识库卡片、文档列表、首页、登录、质量运营、诊断与账户浮层复用同一套视觉变量；用量图表和 PDF 引用高亮也改用灰绿配色。PDF 仍保留原始纸张颜色。
- 桌面所有页面采用相同的导航顺序、38px 行高和间距，不再因进入问答页而隐藏分组标题、压缩导航或移动入口。工作区导航宽 236px，顶栏高 64px。
- 受保护路由共享一个常驻外壳：导航、账户菜单和顶栏骨架只渲染一次，页面通过 context 注册自己的面包屑、顶栏操作与内容留白；页面分包未加载时先按路径推导选中项，加载后由页面配置接管。
- 最近对话只属于问答页，是消息区左侧的可折叠历史栏；收起后由顶栏按钮恢复，滚动位置、筛选与折叠状态在离开问答页后继续复用。窄屏保留导航抽屉和会话抽屉。

正式行为合同见 [前端规范](10-frontend-spec.md)。本轮没有后端、API、数据库迁移或模型参数修改。

## 切页连续性

1. 会话列表通过现有 React Query 按登录身份、知识库筛选和活跃/归档状态共享。服务端分页仍为每页 50 条；已加载分页在离开并回到问答页后复用。数据保鲜 60 秒，失去订阅后保留 5 分钟。
2. 最近使用的筛选、折叠状态与各筛选下的滚动位置保存在内存中，阅读较长时间不会过期；刷新页面不承诺恢复这类导航状态，切账号或退出会清空。聊天草稿继续沿用此前的持久化机制。
3. 同账号切换筛选时保留上一帧列表，避免请求期间闪空；重命名、归档、删除和权限失效清理会取消较早读取并更新相关缓存。不同账号不复用旧列表，迟到响应也不能写入新账号缓存。
4. 已成功的重命名可以更新共享会话行，不能替换后来选中的会话。归档、删除、导出和重命名继续复用原有错误反馈、确认及操作互斥。
5. 新页面首帧直接读取同一登录身份已经确认的账号信息，消除管理员导航先消失再出现引起的列表位移；身份变化立即隐藏旧角色。
6. 应用外壳在受保护路由间保持挂载，切换页面不会重建导航或账户入口；问答页历史栏的展开状态和滚动位置保存在账号级内存缓存中，不依赖页面重新挂载。
