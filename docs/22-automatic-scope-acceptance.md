# 默认自动检索与动态知识库来源

日期：2026-09-29。本次请求是默认自动检索、允许指定范围，并允许同一会话根据每轮问题使用不同知识库。

## 实现行为

- 新对话直接提问；不传范围默认 `scopeMode=auto`。每轮从数据库重新读取当前可访问知识库，包含后续新建/授权的库；公开标记不授予聊天权限。
- 手动选 1–5 库时推断为 manual，保留原范围及单库配置。旧会话保持 manual；自动/手动模式和手动范围在会话创建后固定，另选范围需新建对话。自动模式每轮来源可以变化。
- 自动检索按内容相关性选择片段，不使用额外模型猜库名。所有可访问库分别召回，候选全局排序、全局 RRF，再统一 Rerank；Embedding 每轮一次，Rerank 输入总数不超过系统 vectorTopN。不受前端100条列表或手动5库限制。
- 自动模式始终使用系统检索/回答设置，引用仅来自本轮 Prompt。全局 Rerank 开关和 strict/fallback 策略保持原语义。
- 自动会话创建时按库创建时间降序/ID升序选首选库，用于现有外键、用量归属和生命周期；它不限定检索范围，但撤权/删除仍会影响整段会话。
- 各轮进入回答 Prompt 的库在输出前去重追加为历史访问依赖。依赖保守累计，编辑、重生成和中断不会移除；未使用且非首选的扫描库不成为依赖。任一依赖库撤权/删除后整个会话不可访问，永久删除清除会话。单库质量页排除自动会话，避免跨库内容归入单库管理视图。
- 前端顶栏、列表、面包屑标注自动状态，侧栏保持全部知识库；手动多选和恢复自动保留草稿。新库引用预览不等待会话范围元数据刷新。
